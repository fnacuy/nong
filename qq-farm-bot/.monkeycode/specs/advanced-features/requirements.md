# Requirements Document

# 高级功能（高级权限体系 + 高级静谧模式）

## Introduction

本项目当前存在四类高级自动化能力：资本模式（宠物护主犬上阵/召回）、沉浸式务农（时段内暂停自动化仅保留好友帮助）、疯狗模式（只帮护主犬快速刷盒子）、以及好友静谧时段（静默时段不进行好友互动）。这些能力当前对全部用户开放，且分散在首页"宠物"、策略设置、自动控制等多个位置。

本功能建立统一的"高级功能"权限体系：新增"高级功能"卡密类型，普通用户需激活后才能使用高级功能；并将资本模式、沉浸式务农、疯狗模式统一收敛到设置页面的"高级功能"分组；同时新增"高级静谧模式"（不偷不帮 / 只不偷菜 / 只不帮忙，支持多个时间段）。

## Glossary

- **高级功能**: 资本模式、沉浸式务农、疯狗模式、高级静谧模式的统称，需高级功能权限方可使用。
- **高级功能卡密**: 卡密类型之一，激活后为用户授予有时长或永久的"高级功能"权限。
- **高级功能权限**: 用户是否可使用高级功能的状态；管理员/超级管理员永久有效，普通用户依赖已激活且未过期的高级功能卡密。
- **资本模式**: 宠物护主犬自动上阵/召回（`capital_mode`），现有功能。
- **沉浸式务农**: 时段内暂停自家农场、偷菜、活动、商店等自动化，仅保留好友帮助（`immersiveFarming`），现有功能。
- **疯狗模式**: 好友互动中"只帮护主犬，快速刷盒子"（`friend_turbo_mode`），现有功能。
- **高级静谧模式**: 新增能力，在可配置的多个时间段内，按所选模式调整偷菜/帮忙行为；包含三个选项：不偷不帮、只不偷菜、只不帮忙。
- **捣乱（放草虫）**: 好友互动中的"自动捣乱"行为（`friend_bad`），由独立开关控制，不受高级静谧模式影响。
- **普通用户**: `role` 为 `user` 的账号；管理员（`admin`）与超级管理员（`super_admin`）属于高级权限用户。

## Requirements

### Requirement 1: 高级功能卡密类型

**User Story:** AS 管理员, I want 创建"高级功能"类型的卡密, so that 可向普通用户分发高级功能权限。

#### Acceptance Criteria

1. WHEN 管理员在后台创建卡密, THE 系统 SHALL 支持选择"高级功能"卡密类型。
2. WHEN 管理员创建高级功能卡密, THE 系统 SHALL 支持配置时长（小时/天）或永久有效。
3. WHEN 卡密列表展示高级功能卡密, THE 系统 SHALL 使用区别于 time / quota / turbo 的独立标识与文案。

### Requirement 2: 高级功能权限模型

**User Story:** AS 普通用户, I want 激活高级功能卡密获得高级功能权限, so that 可使用资本模式、沉浸式务农、疯狗模式与高级静谧模式。

#### Acceptance Criteria

1. WHEN 普通用户激活高级功能卡密, THE 系统 SHALL 为用户记录高级功能权限及其到期时间（或永久）。
2. WHEN 高级功能权限到期, THE 系统 SHALL 将用户高级功能权限判定为失效。
3. WHEN 管理员或超级管理员登录, THE 系统 SHALL 将高级功能权限判定为永久有效。
4. WHEN 高级功能卡密已禁用或已被使用, THE 系统 SHALL 拒绝激活并返回对应错误提示。

### Requirement 3: 设置页面高级功能分组

**User Story:** AS 用户, I want 在设置页面看到"高级功能"分组, so that 集中管理高级功能相关配置。

#### Acceptance Criteria

1. WHEN 用户打开设置页面, THE 系统 SHALL 展示"高级功能"分组。
2. WHEN 用户查看高级功能分组, THE 系统 SHALL 分组内包含资本模式、沉浸式务农、疯狗模式与高级静谧模式四项配置。
3. WHEN 普通用户未激活高级功能权限, THE 系统 SHALL 将高级功能分组置灰禁用并展示激活引导。
4. WHEN 普通用户已激活高级功能权限, THE 系统 SHALL 解除置灰并允许编辑高级功能配置。

### Requirement 4: 功能迁移

**User Story:** AS 用户, I want 资本模式、沉浸式务农、疯狗模式集中到高级功能分组, so that 高级功能统一入口管理。

#### Acceptance Criteria

1. WHEN 用户打开设置页面, THE 系统 SHALL 不再在首页"宠物"、策略设置、自动控制等原位置重复展示资本模式、沉浸式务农、疯狗模式。
2. WHEN 用户配置资本模式、沉浸式务农或疯狗模式, THE 系统 SHALL 保留既有配置字段与行为语义。
3. WHEN 用户将配置保存, THE 系统 SHALL 持久化高级功能分组内的全部配置。

### Requirement 5: 高级静谧模式

**User Story:** AS 用户, I want 配置多个时间段的偷菜/帮忙静默规则, so that 在指定时间段按需停止偷菜或帮忙。

#### Acceptance Criteria

1. WHEN 用户配置高级静谧模式, THE 系统 SHALL 支持添加一个或多个时间段，每个时间段可绑定一种模式：不偷不帮、只不偷菜、只不帮忙。
2. WHEN 模式为"不偷不帮", THE 系统 SHALL 在该时间段停止偷菜与帮忙。
3. WHEN 模式为"只不偷菜", THE 系统 SHALL 在该时间段停止偷菜并继续帮忙。
4. WHEN 模式为"只不帮忙", THE 系统 SHALL 在该时间段停止帮忙并继续偷菜。
5. WHEN 任意高级静谧模式时间段生效, THE 系统 SHALL 保持捣乱行为不受影响。
6. WHEN 时间段跨越午夜, THE 系统 SHALL 正确判定当前时间是否处于该时间段。
7. WHEN 用户删除某时间段, THE 系统 SHALL 移除该时间段的静默规则。

### Requirement 6: 后端权限拦截

**User Story:** AS 系统, I want 在自动化执行前校验高级功能权限, so that 未激活用户的高级功能不生效。

#### Acceptance Criteria

1. WHEN 自动化循环调度资本模式, THE 系统 SHALL 在无高级功能权限时跳过执行。
2. WHEN 自动化循环调度沉浸式务农, THE 系统 SHALL 在无高级功能权限时跳过执行。
3. WHEN 好友互动调度疯狗模式, THE 系统 SHALL 在无高级功能权限时按关闭处理。
4. WHEN 好友互动调度高级静谧模式, THE 系统 SHALL 在无高级功能权限时按无静默规则处理。

### Requirement 7: 激活卡密界面支持

**User Story:** AS 用户, I want 在设置页面的激活卡密界面激活高级功能卡密, so that 获得高级功能权限。

#### Acceptance Criteria

1. WHEN 用户在设置页面激活卡密界面输入高级功能卡密, THE 系统 SHALL 成功激活并更新高级功能权限。
2. WHEN 激活成功后, THE 系统 SHALL 展示高级功能权限的到期时间或永久状态。
3. WHEN 用户未激活高级功能权限, THE 系统 SHALL 在高级功能分组展示激活引导与入口。
